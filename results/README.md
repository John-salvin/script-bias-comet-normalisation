# Results

Everything here is generated by the pipeline. Nothing is edited by hand.

```
results/
├── figures/     # the two paper figures, PNG and PDF
├── tables/      # one CSV per notebook
└── logs/        # verification report, executed notebooks
```

Regenerate with `make all`, or remove with `make clean` (which never touches
`data/`).

---

## figures/

| File | What it shows |
|---|---|
| `fig_ipi_zones.{png,pdf}` | **Figure 2 — IPI zone transitions under romanisation.** Three background bands: Parity (IPI < 0.05), Burden (0.35–0.70) and Paradox (> 0.70). Circles mark native script, triangles romanised, arrows connect the two per language. All five Indic languages cross from Burden into Paradox. ENG-DEU (0.465, Burden) and ENG-SPA (0.009, Parity) are plotted as Latin-script reference points. |
| `fig_comet_qn.{png,pdf}` | **Figure 1 — COMET-QN before and after.** Boxplots for the ten (language, script) cells, raw COMET on the left and quantile-renormalised on the right. The mean absolute per-language gap falls from 8.14 points to 0.00 while every within-language rank correlation is unchanged. |

Both are recomputed from the committed workbooks by notebook 09, which prints a
self-check line whose values must match `paper_numbers.yaml`.
